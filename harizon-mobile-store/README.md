# Harizon - Premium Mobile Store

Harizon is a modern, responsive e-commerce interface dedicated to premium smartphones, smartwatches, and accessories. It provides a sleek user experience for browsing the latest mobile technology.

## Features

- **Storefront**: Showcases featured phones, top deals, and new arrivals with a clean, grid-based layout.
- **Product Catalog**: Comprehensive listings of smartphones and accessories with detailed specifications.
- **User Authentication**: Login and Registration pages for customer accounts.
- **Contact & Support**: Support channels including a contact form and a feedback section.
- **Responsive Navigation**: Mobile-first navigation with a smooth toggle menu.
- **Modern UI**: Utilizes modern aesthetic principles with hover effects, card layouts, and refined typography.

## Technologies Used

- **HTML5**: Semantic markup for better SEO and accessibility.
- **CSS3**: Custom styling including variables, flexbox, grid, and media queries for responsiveness.
- **JavaScript**: For dynamic interactions such as the navigation toggle.

## Getting Started

To explore the store:

1. Clone or download the repository.
2. Navigate to the `harizon-mobile-store` directory.
3. Open `index.html` in your web browser.

## File Structure

- `index.html`: Home page with hero section and featured products.
- `product.html`: Full product catalog.
- `about.html`: Company information.
- `contact.html`: Customer support contact form.
- `feedback.html`: User feedback collection.
- `login.html` / `signup.html`: User authentication pages.
- `assets/`: Directory for CSS styles, images, and other static assets.
