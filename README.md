# BIS Ecommerce Frontend Projects

This repository hosts two distinct ecommerce frontend projects developed using HTML, CSS, and vanilla JavaScript.

## Projects

### 1. [Gourmet Haven Restaurant](./gourmet-haven-restaurant)
An elegant dining website featuring a menu showcase, reservation system, and customer feedback forms.

### 2. [Harizon Mobile Store](./harizon-mobile-store)
A modern, responsive mobile store interface for browsing and purchasing smartphones and accessories.

## Getting Started

To explore these projects:

1. Clone this repository.
2. Navigate to the respective project directory (`gourmet-haven-restaurant` or `harizon-mobile-store`).
3. Open the `index.html` file in your browser to view the project.
