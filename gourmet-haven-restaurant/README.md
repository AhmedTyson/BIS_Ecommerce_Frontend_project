# Gourmet Haven Restaurant

Gourmet Haven is a premium dining website designed to offer users an elegant and seamless experience when exploring our menu, making reservations, and learning about our culinary story.

## Features

- **Home Page**: Welcomes guests with a beautiful hero section, chef's specials, and customer favorites.
- **Menu**: Detailed display of our exquisite dishes including pastas, steaks, desserts, and more.
- **Reservations**: Easy-to-use contact form for booking tables.
- **About Us**: Information about our rich history and culinary philosophy.
- **Feedback**: A dedicated section for guests to share their dining experiences.
- **User Accounts**: Login and Sign-up functionality for a personalized experience.
- **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices.

## Technologies Used

- **HTML5**: For semantic structure and accessibility.
- **CSS3**: For custom styling, layouts, and responsive design (using Flexbox and Grid).
- **Vanilla JavaScript**: For interactive elements like the mobile navigation menu.

## Getting Started

To view the project locally:

1. Clone or download the repository.
2. Navigate to the `gourmet-haven-restaurant` directory.
3. Open `index.html` in your preferred web browser.

## File Structure

- `index.html`: Main landing page.
- `about.html`: Information about the restaurant.
- `product.html`: Menu listings.
- `contact.html`: Contact and reservation form.
- `feedback.html`: Customer feedback form.
- `login.html` / `signup.html`: content for user authentication.
- `assets/`: Contains images, CSS stylesheets, and other resources.
